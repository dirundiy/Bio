# AP Biology Unit 3: Cell Energetics

An interactive study site for AP Biology Unit 3 (topics 3.1–3.7): enzyme structure and catalysis, environmental effects on enzymes, cellular energy, photosynthesis, cellular respiration, and fitness.

It includes:

- Enzyme simulators (temperature, pH and inhibitors)
- A clickable thylakoid membrane
- A respiration stepper and a "what if" panel for mitochondrial inhibitors
- A pigment absorption spectrum
- A summary of the three Unit 3 labs
- A practice test, free-response prompts and flashcards

Open `index.html` in a browser, or view it on GitHub Pages. It's a single file with no build step.
