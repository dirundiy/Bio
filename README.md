# AP Biology Unit 3: Cell Energetics

An interactive study site for AP Biology Unit 3, covering topics 3.1–3.7.

- **Enzymes (3.1–3.3):** simulators for temperature, pH and inhibitors.
- **Photosynthesis (3.5):** stage tabs for Overview, Light reactions, Calvin cycle, Pigments & rate, and a 100-question quiz.
- **Cellular respiration (3.6):** stage tabs for Overview, Glycolysis, Pyruvate oxidation, Krebs cycle, ETC & chemiosmosis, Fermentation, and a 100-question quiz.
- **Also included:** labs, a mixed practice test, free-response prompts and flashcards.

## Files

- `index.html`: the site.
- `ps-questions.js` and `cr-questions.js`: the photosynthesis and respiration question banks.
- `unit3-cell-energetics.html`: the source page, used to build `index.html`.

It's a static site with no build step on the server. Every push to `main` redeploys on Vercel.
